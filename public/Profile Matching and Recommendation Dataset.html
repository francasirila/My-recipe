About Dataset

Overview

This dataset contains structured user profiles and interaction feedback designed for building and evaluating profile matching and recommendation systems.

It includes detailed profile information such as demographic attributes, professional background, personality type, and descriptive text fields, along with simulated user interaction records indicating acceptance or rejection of recommended matches. These datasets support machine learning workflows involving similarity analysis, compatibility scoring, classification, and recommendation modeling.

Key Applications

The dataset is suitable for developing systems such as:

  • Profile matching platforms
  • Recommendation engines
  • Professional networking systems
  • User compatibility analysis tools
  • Intelligent matching applications

It can be used for tasks involving:

  • Natural Language Processing (NLP)
  • Ranking and similarity algorithms
  • Supervised learning models
  • Recommendation system development
  • Model evaluation and experimentation

Dataset Contents

users.csv
Contains structured user profile data including:

  • User identifiers
  • Demographic information
  • Professional summaries
  • Personality types
  • Interest descriptions
  • Text fields for similarity analysis

feedback.csv
Contains simulated interaction data including:

  • User interactions with recommended profiles
  • Acceptance or rejection responses
  • Behavioral feedback records
  • Timestamped activity data

Data Source and Creation

All data in this dataset was independently created to simulate realistic user behavior and structured profile information. The records were generated using consistent templates and controlled logic to ensure data quality, usability, and reproducibility for machine learning experiments and system development.

This dataset is intended for:

  • Machine learning research
  • Recommendation system development
  • Similarity and matching analysis
  • Educational and experimental purposes
  • Prototype and application testing

About this file

users.csv — User Profile Data

This file contains structured user profile information used in a profile matching and recommendation system. Each row represents a unique user with demographic details, professional background, personality type, and descriptive text fields used for similarity analysis.

Key Fields

  • user_id — Unique identifier for each user
  • name — User name
  • age — User age
  • location — City or region
  • profession — Professional role or occupation
  • professional_summary — Brief description of career background
  • about_me — Personal traits and interests
  • mbti — Personality type classification
  • interests — List of user interests

Purpose

Used for building and testing machine learning models that perform profile matching, similarity analysis, and recommendation ranking.
